# Arthur — source registry

Sources are references for informed design reasoning, not blanket mandates. Distinguish normative accessibility criteria from design advice, trend prediction and gallery inspiration. Note applicability and source date when known; do not invent research findings or quote paid content verbatim.

## Supplied style and trend sources

- WebValley — https://web-valley.ru/articles/stili-veb-dizajna — vocabulary of styles, not performance evidence.
- Yandex Practicum — https://practicum.yandex.ru/blog/stili-saytov-v-veb-dizayne/ — styles and contemporary techniques.
- Tilda Education — https://tilda.education/courses/web-design/designsystem/ — design-system foundations.
- Kirki (2027 forecast) — https://kirki.com/blog/web-design-trends-for-2027/ — forecast, not established 2027 outcomes.
- WebFX — https://www.webfx.com/blog/web-design/web-design-trends/ — trends and commentary.
- GIT Infosys — https://www.gitinfosys.com/new-web-design-trends — trends and commentary.
- Tilda (2026) — https://tilda.education/web-design-trends-2026 — 2026 trend examples.

## UX, system and technical reference sources

- Nielsen Norman Group heuristics — https://www.nngroup.com/articles/ten-usability-heuristics/ — expert heuristics, not specific test results.
- Baymard Institute — https://baymard.com/research-articles/current-state-product-list-and-filtering — e-commerce patterns; apply only to comparable tasks.
- GOV.UK Design System — https://design-system.service.gov.uk/components/ — robust task-oriented component patterns.
- IBM Carbon — https://carbondesignsystem.com/ — enterprise/product UI systems, tokens and patterns.
- W3C WAI — https://www.w3.org/WAI/ — accessibility criteria and design guidance.
- WAI ARIA APG — https://www.w3.org/WAI/ARIA/apg/ — interactive pattern semantics/keyboard guidance.
- Practical Typography — https://practicaltypography.com/ — typographic craft.
- Every Layout — https://every-layout.dev/layouts/ — compositional primitives.
- Design Tokens Community Group — https://www.designtokens.org/ — token data format.
- web.dev — https://web.dev/articles/vitals — performance-related guidance.
- Laws of UX — https://lawsofux.com/ — heuristic interpretations, not universal laboratory guarantees.

## Confidence labeling

**Confirmed:** explicitly approved requirements, observable project facts or applicable standard.

**Supported contextually:** relevant research or guidance with an identifiable domain of applicability.

**Hypothesis:** visual taste, predicted engagement, trend forecasts or untested UX trade-offs. Submit material hypotheses for approval.

Do not auto-browse all links for every task. Load only relevant local summaries and verify external claims only when needed by the actual assignment.
